# Game

Juego narrativo histórico: Versalles, 1722.

- [REGLAS.md](REGLAS.md): canon de reglas.
- [AGENTS.md](AGENTS.md): instrucciones para cualquier IA que trabaje aquí (proponer antes de ejecutar).
- [COLABORAR.md](COLABORAR.md): cómo está organizado el código y cómo trabajar en él (para cualquier IA o persona).
- `web/`: el **Escritorio de Versalles** (abrir `web/index.html`). `web/libro.html` es el libro de caras completo.
- `canon/`, `mapa/`: datos base.
- `narrador/`: verdad del narrador (no abrir si juegas).
